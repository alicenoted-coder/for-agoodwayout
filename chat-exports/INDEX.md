# 女子出走社 聊天記錄匯出檔清單

LINE 社群「女子出走社」主聊天室的匯出檔記錄。每次匯出的都是**完整記錄**（從加入社群那天到匯出當下），所以每份檔案都會和上一份重疊，「比上一份新增」那一欄才是這次真正多出來的部分。

> 匯出檔含有成員的發言內容，**`.txt` 檔不會上傳到 GitHub**（已經寫在 `.gitignore`），只有這份清單會上傳。

## 檔案清單

表格中除了「用途／產出」以外，其他欄位都是程式自動產生的，不用手動修改。

**欄位說明**
- **訊息起／訊息迄**：檔案裡第一則和最後一則訊息的日期
- **成員訊息數**：不含系統訊息（加入、收回）和 Auto-reply 等 LINE 內建自動程式
- **比上一份新增**：這份比上一份多出來的日期範圍。如果出現 ⚠️，代表這份的開頭比上一份晚，手機裡的舊記錄可能不見了，**舊檔要保留，不要刪**
- **用途／產出**：手動填寫，例如用這份產出了哪份報告、整理到哪一天

## 用法

### 每週一：匯出並登記

1. **匯出**：社群 → 右上角選單 → 設定 → 傳送聊天記錄 → 存到檔案（選單名稱依 LINE 版本可能不太一樣）
2. **命名**：`agoodwayout_YYYY-MM-DD.txt`，日期用匯出當天。用英文和數字，中文檔名上傳後會變成底線
3. **放檔案**：放進這個 `chat-exports/` 資料夾
4. **更新清單**：執行下面的指令，表格會自動新增一列
   ```
   python3 tools/update_index.py
   ```
5. **填用途**：在新那一列的「用途／產出」欄位寫上用途，例如「第 45 週摘要」

### 整理時要注意

- **只整理「比上一份新增」的範圍**，前面的部分已經整理過了
- **匯出當天的訊息先跳過**，因為那天還沒結束，等下一份再整理完整的一天
- 只有主聊天室，**討論串和子聊天室的內容不在匯出檔裡**

### 舊檔案

**全部保留，不要刪。** 匯出的內容是手機裡存的記錄，換手機或清除資料後，新的匯出檔可能會少掉前面那一段，舊檔就是備份。
